# Engine D-Carb web brand specification

- Identity: preserve the supplied Engine D-Carb logo and Care4Earth attribution.
- Palette: deep engineering navy (`#041f35`, `#062b49`), signal cyan (`#22bdf2`), action orange (`#ff7a14`), ice (`#eef6fb`) and white.
- Voice: direct, technically careful and workshop-focused. Avoid guaranteed performance, mileage or emissions claims without documented evidence.
- Photography: real workshop context, trained technician, visible machine-to-engine connection, natural light and believable equipment geometry.
- Illustration: diagrams must explain the engine cycle or connected service system. No generic sci-fi decoration.
- Motion: one focal engine animation with restrained supporting transitions. A complete reduced-motion presentation is required.
- Shape: 18–24px section surfaces, compact pills only for statuses or controls, circular forms only for cycle/progress indicators.
- Conversion: vehicle service and machine purchase are distinct journeys with distinct confirmation copy.
